# Gassi

A small, self-hosted dog diary for one household: who walked the dog and when, what and how much the dog ate,
pee and poop. Built for two people on phones, signed in through authentik.

Status: **planning**. Nothing is built yet.

Docs: published with MkDocs Material on GitHub Pages (built from `docs/`).

- [docs/PLAN.md](docs/PLAN.md): what we're building, the first version, stack, and deployment
- [docs/ALTERNATIVES.md](docs/ALTERNATIVES.md): existing tools we evaluated and why we're building our own
